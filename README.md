# Product_Listing_08
This project displays a simple product listing page using HTML and CSS.

Features

- Three product cards
- Product images and names
- Product prices
- Buy Now buttons
- Flexible layout

Technologies Used

- HTML
- CSS

How to Run

1. Open the project folder.
2. Open "index.html" in a browser.

Learning Outcomes

- Practiced CSS Flexbox.
- Learned to create product cards.
- Used CSS styling and hover effects.
